# Output

Results go under `results/` (relative to the job results):

- `S1_PACBIO_ISOCALL/`: alignment and isoform calls
- `S2_TRANSCRIPTOME/`: SQANTI3 QC, hash ids, filtered transcripts
- `S3_PREDICTED_PROTEOME/`: ORFs, CPAT, SQANTI3 protein, protein classification
- `S4_MULTISAMPLE_ANALYSIS/`: LeafCutter and differential expression per comparison
- `pipeline_info/`: reports, trace, software versions
